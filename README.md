# موقع طلبات ايدج للتجارة والتوزيع

صفحة واحدة (`index.html`) فيها الأصناف والسلة وفورم الطلب. الطلب بيتبعت على واتساب أو بيتنسخ.

## تعديل الأصناف والمجموعات
افتح `index.html` بأي محرر نصوص (Notepad أو VS Code) وابحث عن `id="site-data"`.
تحته كل البيانات مكتوبة كنص JSON بسيط:

- `cats`: المجموعات الأساسية (`id` و`name`).
- `subs`: المجموعات الفرعية (`id` و`cat` وهو `id` المجموعة الأساسية و`name`).
- `products`: الأصناف. كل صنف فيه `sku` (الكود) و`name` و`cat` و`sub`. اختياري: `price` و`pcs` و`unit` و`hidden`.
- `settings.whatsapp`: الرقم بالصيغة الدولية بدون +، مثال `201001234567`.

## ملاحظات
- زر "إدارة الموقع" وحفظ ونشر بيشتغلوا على نسخة Claude المنشورة بس.
- الموقع مفيهوش قاعدة بيانات، والطلبات بتوصل واتساب فقط.
- فيه رقم واتساب الشركة جوه الملف، فخلي الريبو Private لو مش عايزه يبان.
